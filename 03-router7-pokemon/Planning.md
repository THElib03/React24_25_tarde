# React Router Project

El proyecto constará de las siguiente tecnologías:
 - React Router versión 7
 - Contextos globales
 - La libería de notificaciones Sonner
 - Estilado de páginas con TailwindCSS

Estructura del proyecto:
```text
src/
|- components/
|   |- NavBar.jsx
|
|- context/
|   |- PokemoonContext.jsx
|
|- layout/
|   |- RootLayout.jsx
|
|- pages/
|   |- Home.jsx
|   |- Search.jsx
|   |- PokemonDetail.jsx
|   |- Favorite.jsx
|
|- routes/
|   |- router.jsx
|   |- paths.js
|
|- App.jsx
|- main.jsx
```
